## Key Concepts Covered

### Task Scheduler
- Max-heap simulation: always schedule the most frequent available task
- Cooldown tracking using a `nextViableTime` map
- Off-by-one insight: next viable time = `currTime + n + 1` (not `currTime + n`)
- **Optimal formula:** `max(tasks.size(), (f_max - 1) * (n + 1) + count_max)`
  - `f_max` = max task frequency
  - `count_max` = number of tasks with max frequency
  - `tasks.size()` handles the dense-tasks case (no idles needed)

### Find the Duplicate Number
- Treat array as implicit linked list: node `i` points to `nums[i]`
- Duplicate value = two nodes pointing to same next → creates a cycle
- **Floyd's Cycle Detection:**
  - Phase 1: slow moves 1 step, fast moves 2 steps → find meeting point inside cycle
  - Phase 2: reset slow to 0, advance both 1 step → meet at cycle entry = duplicate
- **Why phase 2 works:** If F = dist to cycle entry, a = dist from entry to meeting point, C = cycle length, then F = kC - a. Resetting slow to start and advancing both by F steps lands fast exactly at the cycle entry.

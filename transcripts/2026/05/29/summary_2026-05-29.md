## Recurring Weaknesses (Cross-Round Patterns)

### 1. UNIQUE constraint reasoning — **two opposite-direction bugs in one day**
- Round 1: `UNIQUE(eventId, seatId, userId)` — too permissive, would allow double-booking
- Round 2: `UNIQUE(messageId, userId)` on reactions — too restrictive, blocks multi-emoji
- **Drill:** For every UNIQUE, narrate both *what does this allow that it shouldn't* and *what does this block that it shouldn't*.

### 2. Clarifying questions only on prompt
- All three rounds opened with no proactive clarifying questions; only "what are the constraints?" once nudged.
- Improvement appeared in round 3 (asked about file size up front).
- **Drill:** Ritualize a 60-second open: input ranges, semantics (open/closed/half-open), sort order, edge inputs, mutation policy.

### 3. Edge case tracing — assertion instead of demonstration
- Round 1: claimed code handled all edge cases without tracing; round 2: empty-heap `continue` caused `[[0,10]]` to output 0.
- **Drill:** Trace single-element / empty / boundary inputs explicitly before declaring done.

### 4. API design consistently underspecified
- Schema rounds: skipped endpoint shapes entirely.
- System design: described flows but no concrete request/response, no idempotency keys, no status codes.
- **Drill:** During the next system design, force yourself to write at least 2–3 endpoint specs with method, path, request body, response body, idempotency.

### 5. NFR-vs-implementation conflation
- System design: "use S3 for durability" conflated implementation with the 11-nines target.
- **Drill:** State NFRs as measurable targets first; defer implementation to architecture phase.

### 6. Index column order
- Schema round 2: `(createdAt, channelId)` written when query wanted `(channelId, createdAt DESC)`.
- **Rule:** Equality predicate first, range/order predicate second.

### 7. Unjustified denormalization
- Schema round 1: `Venue.seats[]`
- System design: `Folder.files[]`
- **Drill:** Every denorm should name the exact read query it speeds up and the write-side cost.
